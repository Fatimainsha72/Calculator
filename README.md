# 🧮 Basic Calculator
A simple, responsive calculator that performs basic arithmetic operations like addition, subtraction, multiplication, and division. Built using HTML, CSS, and JavaScript—perfect for beginners!

## ✨ Features
- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🔄 Clear/reset functionality
- 🖥️ Responsive design for desktop and mobile

## 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla)
